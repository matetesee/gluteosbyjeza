# Glúteos by Jeza

App de onboarding + panel de entrenamiento (desafío de glúteos de 28 días), construida con React + Vite + Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run start
```

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4

## Deploy

Configurado para desplegar en [Railway](https://railway.app) vía `railway.json` (build con Nixpacks, `npm run build` + `npm run start`).
